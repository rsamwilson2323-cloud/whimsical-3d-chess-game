# ♟️ Whimsical 3D Chess Game

A browser-based **3D Chess Game** built with **React**, **Three.js**, **WebGL**, and **Vite**.

Experience chess in a charming low-poly meadow where expressive 3D characters replace traditional pieces. Play against an AI with adjustable difficulty, enjoy smooth animations, track move history, and explore an immersive WebGL environment designed for both beginners and experienced players.

---

## 🚀 Overview

**Whimsical 3D Chess Game** reimagines the classic game with a vibrant 3D world, animated character-inspired chess pieces, and an intuitive interface. Built using modern web technologies, it demonstrates advanced Three.js rendering, raycasting interactions, React state management, and AI-powered gameplay.

## ⚙️ Installation

### Clone the Repository

```bash
git clone https://github.com/rsamwilson2323-cloud/whimsical-3d-chess-game.git
```

### Navigate to the Project

```bash
cd whimsical-3d-chess-game
```

### Install Dependencies

```bash
npm install
```

### Start Development Server

```bash
npm run dev
```

Open your browser:

```
http://localhost:5173
```

## 🕹️ How to Play

1. Select an AI difficulty.
2. Click one of your pieces to highlight valid moves.
3. Click a destination square to move.
4. Watch captured pieces move into their holding cages.
5. Use **Undo** to experiment with different strategies.
6. Start a **New Game** anytime.
